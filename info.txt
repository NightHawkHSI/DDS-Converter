## TexForge — by DiccChops
===================================================================


# WHAT IT DOES

Converts image files (PNG, JPG, JPEG, TGA, BMP) into multiple output
formats: DDS, PNG, JPG, TGA, BMP, WebP, and SVG.
For DDS output, Microsoft's texconv.exe (DirectXTex) is used to
produce GPU-compressed textures with optional mipmap chains.
All other formats are handled directly via Pillow — no extra tools needed.


# REQUIREMENTS

! texconv.exe — required for DDS output only
! Place it in the same folder as DDS.py / TexForge.exe
~ Download from: https://github.com/microsoft/DirectXTex/releases
~ PNG, JPG, TGA, BMP, WebP, SVG output needs NO extra tools.


# HOW TO USE

+ 1. INPUT FOLDER
   Select the folder containing your source images.

+ 2. OUTPUT FOLDER
   Select where the converted files will be saved.

+ 3. OUTPUT TYPE  —  Choose the target format:

   DDS     DirectX GPU-compressed texture (game engines).
   PNG     Lossless, full alpha support.
   JPG     Lossy, small file size, no alpha.
   TGA     Lossless with alpha, older game pipeline standard.
   BMP     Uncompressed bitmap.
   WebP    Modern lossy/lossless, excellent compression.
   SVG     Raster image embedded as base64 inside an SVG wrapper.

+ 4. DDS FORMAT  —  When output is DDS, choose the codec:

   DXT1            Opaque / 1-bit alpha. Smallest file size.
   DXT3            Explicit alpha. Good for sharp alpha edges.
   DXT5            Smooth alpha / gradients. Most common choice.
   BC4_UNORM       Single-channel greyscale (R only).
   BC5_UNORM       Two-channel (R+G), ideal for normal maps.
   BC7_UNORM       High-quality RGBA. Better than DXT5, slightly larger.
   R8G8B8A8_UNORM  Uncompressed RGBA. No quality loss, largest size.

+ 5. PROFILE
   Pick a game-engine preset to auto-configure DDS mode, codec,
   and mipmap settings for common targets.

+ 6. MIPMAPS
   Tick to generate a full mipmap chain (recommended
   for most in-game textures). Disable for UI / 2D sprites.

+ 7. CONVERT ALL
   Click ▶ START CONVERSION to process every file in
   the input folder at once.

+ 8. CONVERT ONE
   Click the small ▶ button next to any file in the
   queue to convert only that file.


# TINT / SPECULAR COLOUR

Select an image from the FILE QUEUE, then pick a tint colour and
set the intensity. The tint is baked into the image before conversion —
useful for colour-shifted variants, specular colour masks, or
team-colour textures.

   PRESETS       Quick-pick common colours with one click.
   ⊕ CUSTOM      Open a colour picker for any colour you need.
   INTENSITY     Controls how strongly the tint blends (0–100 %).
   MODE          Blending algorithm:

~    Multiply      Darkens — good for shadows / masks.
~    Screen        Lightens — good for glows.
~    Overlay       Contrast boost.
~    Add           Additive brightening.
~    Tint (Lerp)   Simple linear blend.

   APPLY TO ALL  Apply the current tint settings to every file.
   CLEAR TINT    Remove the tint from the selected file only.

~ The BEFORE panel shows a live preview of the tinted source image.
~ The AFTER panel shows the last converted output for that file.


# PROJECTS & TEMPLATES

+  SAVE PROJECT  — saves all folders, settings, tints, and per-file
   format overrides to a JSON file you can reload later.
+  LOAD PROJECT  — restores a previously saved session.
+  TEMPLATE      — quick-create input/output folder pairs with a
   matching preset for Gear, UI, Vehicles, or Weapons assets.
