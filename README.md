# DDS-Converter
DDS Converter by DiccChops. Lightweight Python tool using Microsoft texconv (DirectXTex) to convert images to DDS for FiveM and 3D apps. Extract RAR, run app, choose folder, format, convert. Supports batch, single files, mipmaps, 7 formats, preview, log, themes, auto settings. Inputs PNG JPG TGA BMP outputs DDS. Ready for game and texture pipeline
